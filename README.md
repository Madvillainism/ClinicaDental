# 🦷 Carlodent — Dental Clinic

[![Astro](https://img.shields.io/badge/Astro-5.0-orange.svg?style=flat&logo=astro)](https://astro.build)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Sitio web y landing page moderna, rápida y responsiva para **Carlodent Dental Clinic**. Diseñada para ofrecer una experiencia fluida al paciente, facilitando la reserva de citas y la presentación de servicios odontológicos.

---

## 🚀 Características

- ⚡ **Rendimiento excepcional:** Carga ultra rápida gracias a la arquitectura de islas de Astro.
- 📱 **Diseño 100% Responsive:** Adaptado para dispositivos móviles, tablets y escritorio.
- 🗓️ **Call to Action (CTA) claro:** Acceso rápido para agendar citas y contactar a la clínica.
- 🧩 **Componentes modulares:** Estructura limpia y fácil de mantener/escalar.

---

## 🛠️ Tech Stack

- **Framework:** [Astro](https://astro.build)
- **Estilos:** CSS3 / Vanilla / Scoped CSS
- **Iconos:** SVGs inline / Lucide Icons
